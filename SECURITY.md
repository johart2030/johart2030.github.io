# Security Policy

## About This Project

This repository contains projects and websites published through
[johart2030.github.io](https://johart2030.github.io).

Some projects may use third-party services such as Firebase. Security issues
affecting those services may need to be reported separately to the relevant
service provider.

## Supported Versions

This project is continuously updated from the `main` branch.

| Version / Branch | Supported |
| ---------------- | --------- |
| `main`           | :white_check_mark: |
| Older commits    | :x: |

Only the current version deployed from `main` is actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability in one of the projects in this
repository, please report it privately rather than creating a public GitHub
Issue.

### What to include

Please provide:

- A description of the vulnerability
- The affected website, project, or file
- Steps to reproduce the issue
- The potential security impact
- Screenshots, logs, or a proof of concept if applicable

Please do not include passwords, authentication tokens, API keys, personal
information, or other sensitive information in your report.

### Reporting Method

Please use GitHub's private vulnerability reporting feature when available.

If private vulnerability reporting is unavailable, contact the repository
maintainer privately before publicly disclosing the issue.

### Response

We will try to:

- Acknowledge the report within 7 days
- Investigate and determine the severity of the issue
- Fix or mitigate confirmed vulnerabilities when reasonably possible
- Keep the reporter informed when appropriate
- Credit the reporter for responsible disclosure if they would like to be
  credited

Response times may vary depending on the severity and complexity of the issue.

## Responsible Disclosure

Please give the maintainer a reasonable opportunity to investigate and fix a
security vulnerability before publicly disclosing technical details.

Do not intentionally access, modify, delete, or expose another person's data
while testing a suspected vulnerability.

Thank you for helping keep these projects secure.
