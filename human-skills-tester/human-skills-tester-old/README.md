# Human Skills Tester

A dependency-free, multi-page browser game for GitHub Pages.

## Included tests

- Reaction Time
- Number Memory
- Aim Trainer
- Sequence Memory
- Visual Memory
- Typing Test
- Math Sprint

## Publish

Copy all files and folders into the root of your GitHub Pages repository, commit, and push to `main`. Scores are stored in the visitor's browser with `localStorage`.
